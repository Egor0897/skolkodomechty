# SDM — «Сколько до мечты?»

Бесплатный калькулятор финансовых решений для школьника: когда получится купить мечту, если копить в копилке или на вкладе, во сколько обойдётся кредит, куда уходят мелкие траты, какой вклад выгоднее, как распределить бюджет и как инфляция съедает деньги. Есть страница «Курсы» — курсы валют Банка России и цены криптовалют в прямом эфире.

**Сайт:** https://egor0897.github.io/skolkodomechty/

## Страницы

| Файл | Что делает |
|---|---|
| `index.html` | Накопления: срок для копилки и вклада с учётом роста цен, график |
| `credit.html` | Кредит: платёж, переплата, сравнение с накоплением, предложения Сбера |
| `expenses.html` | Мелкие траты: сколько уходит в месяц и в год |
| `deposits.html` | Вклады: сравнение трёх вкладов, эффективная ставка, вклады Сбера |
| `budget.html` | Бюджет по правилу 50/30/20 |
| `inflation.html` | Инфляция: цена через несколько лет |
| `rates.html` | Курсы: валюты ЦБ РФ и криптовалюты (Binance) онлайн |

## Как устроено

- `js/finance.js` — все расчёты (деньги хранятся в копейках, округление как в банке).
- `js/app.js` — формы, пересчёт на лету, графики, предложения Сбера.
- `js/live.js` — прямой эфир: курс ЦБ (cbr-xml-daily.ru), цены с биржи Binance через WebSocket, запасной источник — CoinGecko.
- `css/style.css` — оформление: тёмно-зелёный переливающийся фон, стеклянные карточки.
- `fonts/` — шрифты Unbounded и Onest (SIL Open Font License), загружаются с самого сайта.

Сайт статический: работает на GitHub Pages и открывается двойным щелчком по `index.html` (курсам нужен интернет).

Расчёты приблизительные и не являются финансовой рекомендацией. Проект не связан с ПАО Сбербанк.
